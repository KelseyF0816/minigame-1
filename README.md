# Minigame 1
## Devlog
I think of a Unity Scene as a theater stage. GameObjects are the actors, props, lights, and cameras arranged on that stage. Components give each object its appearance and abilities. A Renderer is like a costume that makes an object visible, a Collider defines where it can make contact with other objects, and a script gives it directions for how to behave.

In my platforming level, the player, coins, and spikes are different GameObjects in the same Scene. The player’s movement component lets the player move and jump. The coins have components that make them visible and detect contact, while the game’s scripts handle collecting them and adding points. Like a stage production, the Scene brings these objects together, and their Components determine how they take part in the game.
